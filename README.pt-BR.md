## Áreas de atuação

- **Arquitetura de software e sistemas backend** — design modular, fronteiras claras, APIs, bancos de dados e automação.
- **Ciência de dados e sistemas inteligentes** — aplicações com LLMs, aprendizado de máquina e modelagem de séries temporais.
- **Matemática aplicada** — algoritmos, complexidade, métodos numéricos, sistemas dinâmicos e controle.
- **Ferramentas para desenvolvedores e agentes de IA** — skills reutilizáveis, governança, gestão de contexto e fluxos estruturados de desenvolvimento.
